# LOVE♡マシーン3｜マルチアカウント・エンジン

> ⚠️ **2026-10-22 改定（主張の重心を移した）。**
> 旧版は主張が免罪（あなたのせいじゃない／構造の話）で終わっていて、読者が本当に欲しい
> 「で、どう動けば変わるのか」が弱かった。**免罪は1行まで。主張の本体は処方**に移した。
> 変えたのは3章・4章・5章・7章・9章の2章スロット。型とCTAの7ブロック構成そのものは変えていない。

**このファイルにキャラの話は「カード」の形でしか書かない。**
エンジンが知っているのは「5本の作り方」だけで、「誰で作るか」は毎回カードから読む。

## 0. 3層構造（これがマシーン3の本体）

```
[エンジン層]  この章と1〜7章    ← 5本の設計・生成手順・出力形式。アカが増えても不変
[コア層]      型51〜115／7ブロックCTA／表記 ← 全アカ共有（8章に参照先）
[アカ層]      アカウントカード   ← 1枚＝1アカ。11スロット。ここだけが違う
[記録層]      使用ログ           ← アカごとに独立。型とCTA番号の重複を防ぐ
[検算層]      check.py           ← 1本のスクリプトが、カードの10章を読んで全アカを検算する
```

**アカウントを増やしても、増えるのはカードとログだけ。**
エンジンとコアを書き換えたくなったら、それはカードに書くべきことが漏れている合図。

⚠️ **正本はユーザーのフォルダ `love-machine-3/`**（`SKILL.md` / `core/` / `accounts/` / `logs/` / `tools/`）。
そのフォルダが読める状況なら、必ず `accounts/<ID>.md` の全文を読む。
読めない時だけ、このファイルの9章の要約カードで作る。

## 2. 生成手順

1. そのアカのログを読む。**直近2回で使った 型番号／CTA[7]の番号／在庫**を確認する
2. アカウントカードを**全部**読む（剣なら `ken-style.md` も）
3. 型カタログから、直近2回で使っていない型を5つ引く。5本とも別の型。**1〜2本は型101〜115から**
4. 7ブロックCTAとバリエーション番号帳を読む
5. 5本の設計を決める（3章）
6. 生成する。**1本＝1型**。誘導つき2本だけ、最終スレッドを7ブロックCTAにする
7. `check.py` を通して**違反0**にする
8. 最終チェック（7章）を全部通す
9. ログに1行追記する

```bash
python3 tools/check.py 出力.md --account <ID>
```

⚠️ 投稿はコードブロックで囲まないとチェッカーが読めない。**ツリーは1スレッドごとにブロックを分ける。**

## 3. 5本の設計（全アカ共通・ここは崩さない）

| | 本数 | 締め方 |
|---|---|---|
| 誘導つき | **2本** | 最終スレッドを7ブロックCTAにして、末尾に誘導先 |
| 誘導なし | **3本** | 誘導を一切置かない。答えを出し切って単体で完結させる |

- テーマ配分は**カードの3章**どおり（2軸3本／2本が標準。リョウだけA3・B1・C1）
- 誘導つき2本は**別の軸から1本ずつ**。誘導先も別の枠から引く。同じ枠を1日に2回出さない
- 誘導なし3本は**出し惜しみしない**。型の誘導・匂わせ工程は削って、**今夜そのまま実行できる1手**に置き換える。
  免罪・余韻で埋めない（ここが旧版の事故。免罪は最後の1行だけ）。保存・フォローを促す一言も置かない
- 🚨 **5本とも「今夜やる1手」が入っているのが正しい。**誘導なしの回も処方を出し切る。
  渡せるものが無い回は、型ではなくテーマの選び方を間違えている
- 「誘導なしでも成立」と書いてある型（型62・86・91・92・109・110・112 など）を誘導なし枠に優先して回す

### 型と7ブロックCTAのつなぎ方（ここでよく事故る）

- **型の「推奨フックの型」は必ず使う。**外すと型を使った意味がなくなる
- 型が単発指定でも、誘導つきの本はツリーにする。単発のまま使えるのは誘導なし枠だけ
- **枚数はカードの4章が勝つ。**型が3〜4枚を要求しても、カードが2枚と言っていれば2枚に畳む
  （工程を削るのではなく1枚目に圧縮する）
- 🚨 **単発メインのアカ（剣・みさ）は、型がツリーを要求しても畳む。**
  剣は誘導なし3本が単発固定・誘導つきも1スレッド優先で、**5本中3本以上が単発**になるのが正しい
- 型がアカの看板から外れる要求をしてきたら、**カードの11章「翻訳ルール」**で吸収する。型は書き換えない

## 4. 締め方（誘導つき2本だけ）

```
[1] 耳障りのいいこと・都合のいいことを書いて共感させる（2〜3行）
[2] 温度を落として、このまま行った先を見せて不安にさせる（2〜3行）
[3] なぜ相手が行動に移せないのかを説明する（**2行**）★カードの2章のモデルどおり
[4] 今困っていることを、動作で名指しする（1〜2個）
[5] 小さい数字を1つ置く
[6] 解決策をひとつだけ、今夜そのまま実行できる形で渡し切る（**3〜4行。いちばん行数を使うのはここ**）
[7] 手に入るものを一言で断定 → 改行 → URL
```

- 🚨 **[3]のモデルはアカごとに違う。混ぜたら別人になる。**カードの2章をそのまま使う
- 🚨 **免罪は1投稿1行まで。**[3]で「あなたのせいじゃない」まで言ったら、そこで止めて[6]の動作に入る。
  免罪を2行以上重ねた回は、読者から見ると「慰められただけで何も渡されなかった投稿」になる
- 🚨 **[3]より[6]を長くする。**理由の説明が処方より長い回は書き直す（旧版はここが逆だった）
- 🚨 **読者が男のアカ（みさ）は、7ブロックを立場反転して読む。**[1][4][6]を全部、読者＝男の側の動作で書く
- [5]は統計風の盛り禁止（9割の男は／100人に聞いたら／◯◯%）。こちらが数えた数だけ
- [6]は出し惜しみしない。ケチると「不安にさせただけの投稿」になる
- URLは最終スレッドの末尾だけ。1枚目・途中には貼らない
- **[2][5][6][7]の番号は誘導つき2本で全部ずらす。**直近2回で使った[7]は引かない

バリエーション番号（詳細は love5 スキルの付録E）：
- **[7]（手に入るもの）12種**：順番／分け方／残りの◯個／文例そのまま／時期／台無しになること／効いてるかの確認法／タイプ別の出し分け／失敗後の戻し方／言われた時の返し方／どこまでやるかの線／体験の続き
- **[5]（数字）10種**：個数／期間／日数／回数／段階／行数・通数／順位／一発判定／時間帯／箇所
- **[6]（渡し方）8種**：停止／置換／追加／順序替え／待機／二択化／判定だけ／切り上げ
- **[2]（不安の作り方）6種**：時間／固定化／学習／上書き／摩耗／反転

## 5. 書き方（全アカ共通・カードの6章が上書きする）

- **1〜2行目で「恋愛のどの場面か」を出す**（彼／好きな人／元カレ／LINE／既読／連絡／返事／デート）
- **中学生でも分かる言葉だけ。**抽象語（回路／構造／可能性／状態／位置づけ）を使わない
- **体験談はカードの8章の在庫からしか引かない。**在庫に無い出来事を書かない
- 人間味は**①言われたセリフ ②身体反応 ③都合の悪い動機 ④時間の単位**の4つだけ。**1投稿に1個**
- **救済は免罪ではなく処方で出す。**刺したまま終わらせないが、「あなたのせいじゃない」で終わらせない。
  **必ず「今夜これをやる」まで書く。**免罪は締めの1行だけに置く（剣だけ例外。下の7章を見る）
- 作った実績数字を出さない
- 投稿の頭に字数を1行（例：`3スレッド・約90字＋250字＋280字`）／**スライド番号は書かない**
- 読点「、」は基本ゼロ。1文＝1行。文の途中で改行しない
- 絵文字・ハッシュタグ・ダブルクォート・emダッシュ 禁止。強調は「」。閉じカギの直後に句点を付けない
- **NGワード**：しね／死／しぬ／殺／殴／叩／蹴 を出力前に全文検索して0件
- **二人称はアカ間で貸し借りしない**（「あなた」は剣のみ／みさは二人称ゼロ）

## 10. アカウントを増やす

1. `accounts/_TEMPLATE.md` をコピーして `accounts/<新ID>.md` にする
2. **11スロットを埋める**（1基本情報／2モデル／3テーマ配分／4枚数と字数／5語尾／6表記の差分／7絶対NG／8在庫／9誘導先／10機械検算ルール／11翻訳ルール）。埋まらないスロットがあるうちは投稿を作らない
3. `logs/<新ID>.md` を作る
4. 1章「起動」の一覧に1行足す
5. `python3 tools/check.py サンプル.md -a <新ID>` が動くか確認する
6. **エンジンとコアは1文字も触らない**

### 増やす前の3つの確認

- [ ] **2章のモデルが既存5アカと違うか**（順位／距離／逃げた側／言葉が出ない／教わってないだけ）。同じなら新アカを作る意味がない
- [ ] **二人称が既存と衝突しないか**（「あなた」は剣が使用中）
- [ ] **在庫が8個以上あるか。**薄いアカは3日で作り話に手を出す

### 直す場所の早見表

| 起きたこと | 直す場所 |
|---|---|
| 5本が同じ投稿に見える | CTAバリエーションの番号を散らす／ログを見て型を選び直す |
| CTAが毎回同じ売り文句 | [7]の番号。直近2回を引かない |
| 特定アカだけ口調が崩れる | そのカードの5・6・7章 |
| 投稿が長くなる・ツリーが増える | そのカードの4章（剣・みさは単発メイン） |
| 慰めただけで終わっている・保存されない | 4章の免罪1行ルールと[6]の行数。カードの2章「処方」を出す |
| 全アカで同じクセ | コアの書き方（5章） |
| 検算をすり抜けるNGがある | そのカードの10章にパターンを足す（**check.pyは触らない**） |
| アカを増やしたい | `_TEMPLATE.md` をコピー |

**`check.py` にアカ名を書き足したくなったら設計が壊れている。**チェッカーはカードを読むだけ。
